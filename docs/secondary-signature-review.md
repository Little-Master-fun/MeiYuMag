# 二级管理员签章协办

## 身份和入口

- `admin`：一级管理员。个人首页“审核台”内新增“用户管理”，可查看全部注册用户，按邮箱/组织搜索、筛选身份、指派或撤销二级管理员及调整申请权限。
- `secondary_admin`：保留普通用户的个人申请、日历、信箱功能，额外提供“签章工作台”（独立路由 `/signatures`）。不能列出用户、改角色、人工初审或最终批准申请。
- `user`：普通用户。

## 美育场地流程

1. 用户按原流程提交申请，初审通过后提交签章材料。
2. 有可用二级管理员时，进入 `pending_secondary_review`，指派一位并邮件通知。仅该协办人可读取、下载、审核这份申请。
3. 二级管理员通过审核：进入 `pending_secondary_signature`；不通过：填写原因，退回申请人补交签章材料并邮件通知。用户修正后重新进入签章审核。
4. 二级管理员完成再次签字盖章，上传一份 PDF/PNG/JPEG 扫描件（多页推荐合并 PDF，最大 30 MB）。类型为 `meiyu_countersigned_scan`，保留历史版本，原始用户文件不覆盖。
5. 转为 `pending_admin_submit`，邮件通知一级管理员，由其下载并最终确认。

没有可用二级管理员时，签章材料直接交一级管理员，保持原有流程。悦园三楼、钥匙借用、AI 初审失败转人工的流程不变，通知仍只发一级管理员。

## 指派和权限边界

- 多位二级管理员时，优先沿用原协办人；首次按用户 ID 顺序指派一位，排除申请人自己。不是向所有二级管理员开放所有申请。
- 指派角色只影响后续提交/补交的签章材料，不强行搬动已经进入一级管理员待办的旧申请。
- 取消二级管理员身份立即撤销其工作台/他人文件访问权限。未完成的签章审核、再次签章任务自动重派；若无人可接手，交回一级管理员并通知。
- 用户补交后，旧二次签章文件标记为过期需修正，不能跳过新的签章环节。
- 二级管理员不能审核自己的申请，不能直接最终确认、取消他人的申请，不能调用用户管理或一级管理员审核接口。
- 邮件发送失败会记录 NotificationLog，不丢弃待办或回退已上传材料；不代表邮件已经送达。通知不附带公开材料链接，需登录后下载。
