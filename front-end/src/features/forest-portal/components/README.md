# 申请档案与审核台

`WorkflowDesk.vue` 复用纸张面板，用于新申请选择、个人档案、文件版本下载以及管理员审核。
个人页申请行打开档案，档案的签章、补交和重提按钮发出 `submit` 事件，由 `ForestPortal` 驱动现有 3D 信封运镜。
审核台可从场景右上角打开，也可由管理员访问 `/admin/applications`。

文件用途与接口提交集中在 `../submission.ts`；状态文案、文件标签和下载集中在 `../workflow.ts`。
`ApplicationGuide.vue` 是“使用指南”纸页，含操作步骤、审核状态说明和材料下载。`../materialLibrary.ts` 负责共享材料目录和按申请类型匹配原表/示例。签章用途通过后端模板的 `aliases` 关联原表，不提供伪造签章。
指南和木牌下载不改变申请状态，也不触发信封文件选择。指南支持键盘焦点约束、Escape 关闭、窄屏内部滚动；标题、章节导航与关闭按钮始终保留在可见区域。
补交和签章要求由申请详情的 `required_files` 提供。多项材料需要用户在信封内逐份选择用途，每种用途恰好一份才能确认。

部署前执行后端 `alembic upgrade head`。迁移新增结构化补交清单与处理原因，并把已有 AI 失败的历史待初审记录迁为 `ai_rejected`。
